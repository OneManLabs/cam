# Security policy

## Supported version

The default branch is the only supported version.

## Report a vulnerability

Do not make a public issue for a security problem.

Use the private contact form at [onemanlabs.org/contact.html](https://www.onemanlabs.org/contact.html). Give this information:

- The affected version
- The steps to reproduce the problem
- The possible effect
- A possible correction, if you have one

Do not include credentials, private network addresses, or other secrets in a report.
